# 拼豆图纸生成器（Perler Pattern Generator）

把任意照片转成**可以照着拼的拼豆图纸**：颜色映射到真实拼豆色板、输出带行列标注的网格图纸、豆数统计清单，以及成品效果预览图。

## 快速开始

```
双击 start.bat
```

浏览器会自动打开 `http://127.0.0.1:8765`，然后：

1. **上传图片**：点击虚线框或直接拖图进去；
2. **设置网格**：填宽高（或用快速选板），调节亮度/饱和度/对比度，选是否抖动；
3. **点「生成拼豆图纸」**：得到图纸、效果预览、豆数统计；
4. **下载**：图纸 PNG / 效果图 PNG / 豆数清单 CSV（Excel 可直接打开）。

手动启动：`python server.py 8765`

## 参数说明

| 参数 | 作用 | 建议 |
|---|---|---|
| 宽×高 | 图纸网格格数 | 29×29 = 1 块标准小板；58×58 = 4 块 |
| 抖动模式 | Floyd-Steinberg 误差扩散 | 照片/渐变开，卡通/色块关 |
| 行列标注 | 图纸边缘每 5 格标号 + 主格线加粗 | 拼大图时强烈建议开 |
| 符号模式 | 每格中心画深浅线 | 需要黑白打印时开 |
| 亮度/饱和度/对比度 | 转换前图像增强 | 手机照片常需要饱和度 +20% 左右 |

## 文件结构

```
perler-pattern-generator/

├── server.py       本地网页服务器（仅标准库+Pillow）

├── palette.json    拼豆参考色板（可自行增删颜色）
├── selftest.py     自检脚本：python selftest.py
└── selftest_output/ 自检生成的示例图纸
```

## 色板说明

`palette.json` 收录了约 58 个常用拼豆颜色（Mard/Makeform 风格厂号）。**颜色值为视觉近似值**，不同品牌批次会有差异。你可以：

- 删掉没库存的颜色，图纸就会只用你现有的豆子；
- 按 `{"code","name","brand_code","hex"}` 格式追加新颜色。

颜色匹配在 **CIE Lab 色彩空间**计算 ΔE 距离，比 RGB 欧氏距离更贴近人眼感知。

## 常见问题

- **双击 start.bat 打不开 / 闪退** → start.bat 会自动探测可用的 Python（跳过微软商店的 python 假别名）。如果仍然失败，把窗口里的报错截图给我；
- **找不到 Python** → 到 python.org 安装 3.10+ 并勾选 "Add python.exe to PATH"；
- **Pillow 装不上（网络问题）** → 手动执行 `python -m pip install pillow -i https://pypi.tuna.tsinghua.edu.cn/simple`；
- **颜色数量太多，买不齐** → 关闭抖动、降低饱和度，或删减 palette.json；
- **图案太小细节糊** → 增大网格尺寸（如 87×87）；
- **手机照片发灰** → 对比度 1.1~1.2、饱和度 1.2；
- **想拼超大图** → 图纸按板分区渲染，豆数清单同时给出总小板数。
